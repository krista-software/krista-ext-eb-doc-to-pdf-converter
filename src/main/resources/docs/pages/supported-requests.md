# Supported Requests

EB Doc To Pdf Converter exposes **3 catalog requests** across **2 areas**. Each links to its detailed
page.

## Document Conversion
| Request | Type | Description |
|---|---|---|
| [Convert Document to PDF](pages/ConvertDocumentToPdf.md) | CHANGE_SYSTEM | Converts an uploaded Word document (.doc or .docx) to PDF. |

## Setup
| Request | Type | Description |
|---|---|---|
| [Test Connection](pages/TestConnection.md) | QUERY_SYSTEM | Runs a real self-test of the bundled conversion libraries. |
| [Health Check](pages/HealthCheck.md) | CHANGE_SYSTEM | Reports JVM heap usage. |
